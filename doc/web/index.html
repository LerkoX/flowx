FlowX

灵活的 Go 语言流水线执行引擎，支持 DAG 编排、多后端执行、条件分支与动态图修改

Go >= 1.23 MIT License DAG 编排 Local / Docker / K8s
快速开始 GitHub

核心特性

FlowX 提供完整的流水线执行能力，从简单的本地脚本到复杂的分布式部署

🌍

DAG 工作流编排

使用 Mermaid stateDiagram-v2 语法定义有向无环图，支持条件边和循环回边，自动并行执行无依赖节点

🚀

多后端执行

支持 Local（本地 Shell）、Docker（容器）、Kubernetes（Pod）三种执行环境，统一接口无缝切换

💡

条件分支控制

基于 pongo2 模板表达式的条件边，动态控制执行路径，支持逻辑运算和元数据引用

🔄

数据传递与提取

通过 codec-block（flowx-yaml）或正则表达式从命令输出提取结构化数据，自动在节点间传递

⏹

暂停与动态修改

流水线可在任意层级暂停，暂停期间可安全添加/删除节点和边，恢复后继续执行

📊

模板引擎

内置 pongo2 模板引擎，支持 60+ 内置过滤器和 6 个自定义过滤器（toJson/toYaml/toBase64 等）

📦

元数据存储

支持 in-config（内存）、Redis、HTTP 三种后端，自动按 pipelineId 隔离数据

📣

事件驱动架构

完整的生命周期事件系统（Init/Start/Finish/NodeStart/NodeFinish 等），支持自定义监听器

📸

快照与恢复

支持导出运行时状态为 YAML，已完成的节点在恢复时自动跳过，从中断处继续执行

快速开始

几行代码即可运行你的第一个流水线

main.go
package main import ( "context" "fmt" "github.com/LerkoX/flowx" ) func main() { ctx := context.Background() rt := flowx.NewRuntime(ctx) config := ` Version: "1.0" Name: hello-pipeline Executors: local: type: local config: shell: bash Graph: | stateDiagram-v2 [*] --> Hello Hello --> [*] Nodes: Hello: executor: local steps: - name: greet run: echo "Hello, FlowX!" ` p, err := rt.RunSync(ctx, "hello-001", config, nil) if err != nil { panic(err) } fmt.Println("Status:", p.Status()) }

条件边与分支控制

使用 pongo2 模板表达式定义条件边，实现动态执行路径控制。

  • 支持 ==、!=、>、< 等比较运算符
  • 支持 and、or、not 逻辑运算
  • 可引用 Param 和 Metadata 中的值
  • 条件为 false 的分支自动剪枝
conditional.yaml
Graph: | stateDiagram-v2 [*] --> Validate Validate --> Build : {{ Param.testsPassed }} Validate --> Skip : {{ not Param.testsPassed }} Build --> Deploy : {{ Param.env == "production" }} Build --> Staging : {{ Param.env == "staging" }} Deploy --> [*] Staging --> [*] Skip --> [*]

循环执行

通过条件回边实现可控循环，使用内置 iteration 变量控制迭代次数。

  • 条件回边自动标记，允许有环图
  • iteration 从 0 开始计数
  • MaxLoopIterations 防止无限循环（默认 100）
  • 每次迭代前重置循环节点状态
loop.yaml
MaxLoopIterations: 5 Graph: | stateDiagram-v2 [*] --> A A --> B B --> C C --> A: {{ iteration < 3 }} C --> D D --> [*]

模板引擎与过滤器

基于 pongo2，内置 60+ 过滤器，外加 6 个 FlowX 自定义过滤器

过滤器示例说明
toJson{{ data | toJson }}值转 JSON 字符串
toYaml{{ data | toYaml }}值转 YAML 字符串
toBase64{{ text | toBase64 }}Base64 编码
fromBase64{{ encoded | fromBase64 }}Base64 解码
urlencode{{ url | urlencode }}URL 编码
urldecode{{ encoded | urldecode }}URL 解码
default{{ val | default:"fallback" }}默认值
upper/lower{{ name | upper }}大小写转换
模板使用示例
Param: env: "production" appName: "myapp" namespace: "{{ Param.appName }}-{{ Param.env }}" Nodes: Build: steps: - name: build run: | echo "Building {{ Param.appName }}" echo '```flowx-yaml' echo 'version: "{{ Param.version }}"' echo '```' Deploy: steps: - name: deploy run: echo "Deploy {{ Build.version | toJson }}"

事件监听示例
type MyListener struct{} func (l *MyListener) Events() []flowx.Event { return []flowx.Event{ flowx.EventPipelineNodeStart, flowx.EventPipelineNodeFinish, } } func (l *MyListener) Handle(p flowx.Pipeline, event flowx.Event) { fmt.Printf("Event: %s, Pipeline: %s\n", event, p.Id()) } p, _ := rt.RunSync(ctx, "pipeline-001", configYAML, &MyListener{})

动态图修改

暂停期间安全修改流水线结构

ModifyGraph 示例
mods := flowx.GraphModifications{ RemoveNodes: []string{"OldNode"}, AddNodes: []flowx.NodeConfig{ { Name: "NewNode", Executor: "local", Steps: []flowx.Step{ {Name: "step1", Run: "echo hello"}, }, }, }, AddEdges: []flowx.EdgeModification{ {Source: "NewNode", Target: "ExistingNode"}, }, } err := rt.ModifyGraph(ctx, "pipeline-001", mods)
