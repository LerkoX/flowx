工作流示例

本页面展示使用 FlowX 实现的完整工作流示例，涵盖文件处理、数据 ETL、CI/CD 部署、Docker 构建、天气通知和交互式输入等场景。

示例概览

📂 文件处理工作流

并行执行 codec-block 参数化

自动化日志管理流水线：创建日志目录、生成随机日志、压缩归档、生成清单、清理旧文件。

📊 数据 ETL 工作流

并行采集 codec-block 数据传递

并行采集用户、订单、产品数据，进行格式标准化和转换，生成用户报告和销售报告，最后合并并通知。

🔧 CI/CD 部署工作流

条件边 质量门禁 多环境部署 人工审核

完整的 CI/CD 流水线：代码检出、构建、单元测试、质量检查，支持 dev/staging/production 多环境条件部署，生产环境需人工审核。

🚢 Docker 构建工作流

Docker 执行器 多镜像 数据传递

使用 Docker 执行器运行完整 CI 流水线，Checkout 使用 Alpine 镜像，Build 和 Test 使用 Golang 镜像，Package 使用 Alpine 镜像。

🌤 天气通知工作流

HTTP API 飞书集成 Python 脚本

从天气 API 获取深圳天气信息，通过 Python 脚本处理并调用飞书 API 发送富文本消息通知。

💬 交互式输入工作流

flowx-input 确认交互

展示程序如何通过输出请求用户输入，支持文本输入和确认交互。

文件处理工作流

自动化日志管理流水线，包含以下功能：

  • 初始化并创建日志目录和归档目录
  • 创建随机日志文件
  • 压缩日志文件到归档目录
  • 生成归档文件清单
  • 合并汇总所有任务结果
  • 清理超过保留天数的旧文件

流程图：

stateDiagram-v2
    [*] --> Start
    Start --> CreateDir
    CreateDir --> CompressLogs
    CreateDir --> GenerateManifest
    CompressLogs --> Merge
    GenerateManifest --> Merge
    Merge --> Cleanup
    Cleanup --> [*]

特性：并行执行（CompressLogs 和 GenerateManifest 并行运行）、数据传递（codec-block）、参数化配置、元数据存储。

Version: "1.0"
Name: file-processing-pipeline

Metadate:
  type: in-config
  description: "文件处理元数据，存储日志目录、文件统计等信息"
  data:
    logDir: "{{ Param.projectDir }}/logs"
    archiveDir: "{{ Param.projectDir }}/archives"
    timestamp: "{{ Param.timestamp }}"

Param:
  projectDir: "/var/www/myapp"
  timestamp: "2024-03-28"
  retentionDays: 7
  logPattern: "*.log"

Executors:
  local:
    type: local
    config:
      shell: bash
      workdir: /tmp

Nodes:
  Start:
    executor: local
    name: "初始化"
    steps:
      - name: init
        run: |
          echo "Initializing file processing at {{ Param.timestamp }}"
          echo '```flowx-yaml'
          echo 'startTime: "{{ Param.timestamp }}"'
          echo 'status: "ready"'
          echo '```'

  CreateDir:
    executor: local
    name: "创建日志目录"
    steps:
      - name: create-log-dir
        run: mkdir -p {{ Param.projectDir }}/logs
      - name: create-archive-dir
        run: mkdir -p {{ Param.projectDir }}/archives
      - name: create-random-logs
        run: |
          cd {{ Param.projectDir }}/logs
          for i in {1..3}; do
            timestamp=$(date +%s%N)
            filename="app_${timestamp}.log"
            echo "[$(date)] INFO: Application started" > $filename
            echo "Created log file: $filename"
          done
          echo '```flowx-yaml'
          echo 'logDir: "{{ Param.projectDir }}/logs"'
          echo 'archiveDir: "{{ Param.projectDir }}/archives"'
          echo 'logFilesCreated: 3'
          echo '```'
    extract:
      type: codec-block

  CompressLogs:
    executor: local
    name: "压缩日志文件"
    steps:
      - name: compress
        run: |
          cd {{ Param.projectDir }}/logs
          timestamp=$(date +%Y%m%d)
          archive="{{ Param.projectDir }}/archives/logs_${timestamp}.tar.gz"
          tar -czf $archive $(find . -name "{{ Param.logPattern }}" -type f 2>/dev/null | xargs -n 1) 2>/dev/null
          echo "Compressed logs to: $archive"
          echo '```flowx-yaml'
          echo 'archiveFile: "'$archive'"'
          echo 'compressedCount: "1"'
          echo '```'
    extract:
      type: codec-block

  GenerateManifest:
    executor: local
    name: "生成 manifest 文件"
    steps:
      - name: generate
        run: |
          cd {{ Param.projectDir }}/archives
          manifest="manifest_{{ Param.timestamp }}.txt"
          echo "Archive Manifest - {{ Param.timestamp }}" > $manifest
          ls -lh *.tar.gz >> $manifest 2>/dev/null || true
          echo "Manifest created: $manifest"
          echo '```flowx-yaml'
          echo 'manifestFile: "'$manifest'"'
          echo 'status: "generated"'
          echo '```'
    extract:
      type: codec-block

  Merge:
    executor: local
    name: "合并汇总"
    steps:
      - name: summary
        run: |
          echo "=== File Processing Summary ==="
          echo "Log Directory: {{ CreateDir.logDir }}"
          echo "Archive Directory: {{ CreateDir.archiveDir }}"
          echo "Archive File: {{ CompressLogs.archiveFile }}"
          echo "Manifest: {{ GenerateManifest.manifestFile }}"

  Cleanup:
    executor: local
    name: "清理旧文件"
    steps:
      - name: remove-old
        run: |
          cd {{ Param.projectDir }}/archives
          find . -name "*.tar.gz" -type f -mtime +{{ Param.retentionDays }} -delete 2>/dev/null || true
          echo "Cleanup completed"

数据 ETL 工作流

ETL（Extract, Transform, Load）流水线，包含以下功能：

  • 并行采集用户、订单、产品数据
  • 数据格式标准化和转换
  • 生成用户报告和销售报告
  • 合并所有报告并发送通知

流程图：

stateDiagram-v2
    [*] --> Start
    Start --> CollectUsers
    Start --> CollectOrders
    Start --> CollectProducts
    CollectUsers --> Transform
    CollectOrders --> Transform
    CollectProducts --> Transform
    Transform --> UserReport
    Transform --> SalesReport
    UserReport --> Merge
    SalesReport --> Merge
    Merge --> Notify
    Notify --> [*]
Version: "1.0"
Name: data-collection-pipeline

Metadate:
  type: in-config
  description: "数据采集和处理元数据"
  data:
    collectionDate: "{{ Param.date }}"
    outputDir: "{{ Param.baseDir }}/reports/{{ Param.date }}"

Param:
  date: "2024-03-28"
  baseDir: "/data/analytics"
  apiBaseUrl: "https://api.example.com/v1"
  apiTimeout: 30

Executors:
  local:
    type: local
    config:
      shell: bash
      workdir: /tmp

Nodes:
  Start:
    executor: local
    name: "初始化"
    steps:
      - name: setup
        run: |
          echo "Starting data collection for {{ Param.date }}"
          outputDir="{{ Param.baseDir }}/reports/{{ Param.date }}"
          mkdir -p $outputDir
          echo '```flowx-yaml'
          echo 'outputDir: "'$outputDir'"'
          echo 'startTime: "'$(date -Iseconds)'"'
          echo '```'

  CollectUsers:
    executor: local
    name: "采集用户数据"
    steps:
      - name: fetch-users
        run: |
          echo "Fetching users from {{ Param.apiBaseUrl }}/users"
          outputDir="{{ Param.baseDir }}/raw/{{ Param.date }}"
          mkdir -p $outputDir
          echo '{"users": [{"id": "1", "name": "Alice"}, {"id": "2", "name": "Bob"}], "total": 2}' > $outputDir/users.json
      - name: validate
        run: |
          echo '```flowx-yaml'
          echo 'userCount: 2'
          echo 'dataFile: "{{ Param.baseDir }}/raw/{{ Param.date }}/users.json"'
          echo '```'
    extract:
      type: codec-block

  CollectOrders:
    executor: local
    name: "采集订单数据"
    steps:
      - name: fetch-orders
        run: |
          echo "Fetching orders from {{ Param.apiBaseUrl }}/orders"
          outputDir="{{ Param.baseDir }}/raw/{{ Param.date }}"
          mkdir -p $outputDir
          echo '{"orders": [{"id": "101", "amount": 100.0}, {"id": "102", "amount": 200.0}], "count": 2, "revenue": 300.0}' > $outputDir/orders.json
      - name: validate
        run: |
          echo '```flowx-yaml'
          echo 'orderCount: 2'
          echo 'totalRevenue: 300.0'
          echo 'dataFile: "{{ Param.baseDir }}/raw/{{ Param.date }}/orders.json"'
          echo '```'
    extract:
      type: codec-block

  CollectProducts:
    executor: local
    name: "采集产品数据"
    steps:
      - name: fetch-products
        run: |
          echo "Fetching products from {{ Param.apiBaseUrl }}/products"
          outputDir="{{ Param.baseDir }}/raw/{{ Param.date }}"
          mkdir -p $outputDir
          echo '{"products": [{"id": "1", "name": "Product A"}, {"id": "2", "name": "Product B"}], "total": 2}' > $outputDir/products.json
      - name: validate
        run: |
          echo '```flowx-yaml'
          echo 'productCount: 2'
          echo 'dataFile: "{{ Param.baseDir }}/raw/{{ Param.date }}/products.json"'
          echo '```'
    extract:
      type: codec-block

  Transform:
    executor: local
    name: "数据转换"
    steps:
      - name: normalize
        run: |
          echo "Normalizing data formats"
          outputDir="{{ Param.baseDir }}/raw/{{ Param.date }}"
          targetDir="{{ Param.baseDir }}/processed/{{ Param.date }}"
          mkdir -p $targetDir
          cp $outputDir/users.json $targetDir/users_normalized.json
          cp $outputDir/orders.json $targetDir/orders_normalized.json
          cp $outputDir/products.json $targetDir/products_normalized.json
          echo "Data normalization completed"
          echo '```flowx-yaml'
          echo 'processedDir: "'$targetDir'"'
          echo 'status: "normalized"'
          echo '```'
    extract:
      type: codec-block

  UserReport:
    executor: local
    name: "生成用户报告"
    steps:
      - name: analyze
        run: |
          reportDir="{{ Param.baseDir }}/reports/{{ Param.date }}"
          mkdir -p $reportDir
          echo '{"date": "{{ Param.date }}", "type": "user_report", "totalUsers": 2, "newUsers": 1}' > $reportDir/user_report.json
          echo '```flowx-yaml'
          echo 'userReport: "'$reportDir'/user_report.json"'
          echo 'totalUsers: 2'
          echo '```'
    extract:
      type: codec-block

  SalesReport:
    executor: local
    name: "生成销售报告"
    steps:
      - name: analyze
        run: |
          reportDir="{{ Param.baseDir }}/reports/{{ Param.date }}"
          mkdir -p $reportDir
          echo '{"date": "{{ Param.date }}", "type": "sales_report", "totalRevenue": 300.0, "completedOrders": 2, "pendingOrders": 0}' > $reportDir/sales_report.json
          echo '```flowx-yaml'
          echo 'salesReport: "'$reportDir'/sales_report.json"'
          echo 'totalRevenue: 300.0'
          echo '```'
    extract:
      type: codec-block

  Merge:
    executor: local
    name: "合并报告"
    steps:
      - name: combine
        run: |
          reportDir="{{ Param.baseDir }}/reports/{{ Param.date }}"
          echo '{"date": "{{ Param.date }}", "reports": ["user_report.json", "sales_report.json"], "generatedAt": "'$(date -Iseconds)'"}' > $reportDir/index.json
          echo '```flowx-yaml'
          echo 'indexFile: "'$reportDir'/index.json"'
          echo 'reportDir: "'$reportDir'"'
          echo '```'
    extract:
      type: codec-block

  Notify:
    executor: local
    name: "通知完成"
    steps:
      - name: send
        run: |
          echo "Data collection completed for {{ Param.date }}"
          echo "Reports available at: {{ Merge.reportDir }}"
          echo "Total users: {{ UserReport.totalUsers }}"
          echo "Total revenue: {{ SalesReport.totalRevenue }}"

CI/CD 部署工作流

完整的 CI/CD 部署流水线，包含代码检出、构建、测试、质量检查和多环境条件部署。

流程图：

stateDiagram-v2
    [*] --> Checkout
    Checkout --> Build
    Build --> UnitTests: {{ Param.skipTests == false }}
    Build --> QualityCheck: {{ Param.skipTests == false }}
    Build --> DeployDev: {{ Param.environment == "dev" and Param.skipTests == true }}
    UnitTests --> QualityCheck
    QualityCheck --> DeployDev: {{ Param.environment == "dev" and QualityCheck.allTestsPassed == true }}
    QualityCheck --> DeployStaging: {{ Param.environment == "staging" and QualityCheck.allTestsPassed == true and QualityCheck.codeCoverage >= Param.codeCoverageThreshold }}
    QualityCheck --> SkipDeploy: {{ Param.environment == "staging" and (QualityCheck.allTestsPassed == false or QualityCheck.codeCoverage < Param.codeCoverageThreshold) }}
    QualityCheck --> ProductionReview: {{ Param.environment == "production" and QualityCheck.allTestsPassed == true and QualityCheck.codeCoverage >= Param.codeCoverageThreshold }}
    QualityCheck --> RejectProduction: {{ Param.environment == "production" and (QualityCheck.allTestsPassed == false or QualityCheck.codeCoverage < Param.codeCoverageThreshold) }}
    DeployDev --> [*]
    DeployStaging --> [*]
    ProductionReview --> ManualApproval
    ManualApproval --> DeployProduction
    DeployProduction --> [*]
    SkipDeploy --> [*]
    RejectProduction --> [*]
Version: "1.0"
Name: ci-cd-deployment-pipeline

Metadate:
  type: in-config
  description: "CI/CD 部署流水线元数据"
  data:
    environment: "{{ Param.environment }}"
    buildVersion: "{{ Param.version }}"

Param:
  environment: "staging"
  version: "v1.0.0"
  projectName: "myapp"
  skipTests: false
  codeCoverageThreshold: 80

Executors:
  local:
    type: local
    config:
      shell: bash
      workdir: /tmp

Nodes:
  Checkout:
    executor: local
    name: "代码检出"
    steps:
      - name: checkout
        run: |
          echo "Checking out code for {{ Param.projectName }} version {{ Param.version }}"
          echo '```flowx-yaml'
          echo 'branch: "main"'
          echo 'commit: "abc123"'
          echo 'timestamp: "'$(date -Iseconds)'"'
          echo '```'
    extract:
      type: codec-block

  Build:
    executor: local
    name: "构建应用"
    steps:
      - name: compile
        run: |
          echo "Building {{ Param.projectName }} {{ Param.version }}"
          echo '```flowx-yaml'
          echo 'buildSuccess: true'
          echo 'buildSize: "125MB"'
          echo 'buildTime: 45'
          echo '```'
    extract:
      type: codec-block

  UnitTests:
    executor: local
    name: "单元测试"
    steps:
      - name: test
        run: |
          echo "Running unit tests..."
          echo '```flowx-yaml'
          echo 'testsRun: 50'
          echo 'testsPassed: 50'
          echo 'testsFailed: 0'
          echo 'success: true'
          echo '```'
    extract:
      type: codec-block

  QualityCheck:
    executor: local
    name: "质量检查"
    steps:
      - name: lint
        run: |
          echo "Running code quality checks..."
          echo "Linting: No issues found"
      - name: coverage
        run: |
          echo "Calculating code coverage..."
          allTestsPassed={{ UnitTests.success }}
          codeCoverage=85
          echo "Code coverage: ${codeCoverage}%"
          echo '```flowx-yaml'
          echo 'allTestsPassed: "'$allTestsPassed'"'
          echo 'codeCoverage: "'$codeCoverage'"'
          echo 'lintIssues: 0'
          echo 'securityVulnerabilities: 0'
          echo '```'
    extract:
      type: codec-block

  DeployDev:
    executor: local
    name: "部署到开发环境"
    steps:
      - name: deploy
        run: |
          echo "Deploying {{ Param.projectName }} {{ Param.version }} to DEV environment"
          echo '```flowx-yaml'
          echo 'environment: "dev"'
          echo 'url: "https://dev.example.com"'
          echo 'deployedAt: "'$(date -Iseconds)'"'
          echo '```'
    extract:
      type: codec-block

  DeployStaging:
    executor: local
    name: "部署到预发布环境"
    steps:
      - name: deploy
        run: |
          echo "Deploying {{ Param.projectName }} {{ Param.version }} to STAGING environment"
          echo "Coverage check passed: {{ QualityCheck.codeCoverage }}% (required: {{ Param.codeCoverageThreshold }}%)"
          echo '```flowx-yaml'
          echo 'environment: "staging"'
          echo 'url: "https://staging.example.com"'
          echo 'deployedAt: "'$(date -Iseconds)'"'
          echo '```'
    extract:
      type: codec-block

  ProductionReview:
    executor: local
    name: "生产环境审核"
    steps:
      - name: prepare
        run: |
          echo "Preparing production deployment review..."
          echo "Version: {{ Param.version }}"
          echo "All tests: PASSED"
          echo "Code coverage: {{ QualityCheck.codeCoverage }}%"
          echo "Ready for manual approval"
          echo '```flowx-yaml'
          echo 'version: "{{ Param.version }}"'
          echo 'ready: true'
          echo 'reviewUrl: "https://reviews.example.com/{{ Param.version }}"'
          echo '```'

  ManualApproval:
    executor: local
    name: "人工审核"
    steps:
      - name: approve
        run: |
          echo "Manual approval process..."
          echo "Reviewer: john.doe@example.com"
          echo "Approval: APPROVED"
          echo '```flowx-yaml'
          echo 'approved: true'
          echo 'reviewer: "john.doe@example.com"'
          echo 'approvedAt: "'$(date -Iseconds)'"'
          echo '```'

  DeployProduction:
    executor: local
    name: "部署到生产环境"
    steps:
      - name: deploy
        run: |
          echo "Deploying {{ Param.projectName }} {{ Param.version }} to PRODUCTION environment"
          echo "Approved by: {{ ManualApproval.reviewer }}"
          echo '```flowx-yaml'
          echo 'environment: "production"'
          echo 'url: "https://production.example.com"'
          echo 'deployedAt: "'$(date -Iseconds)'"'
          echo '```'
    extract:
      type: codec-block

  SkipDeploy:
    executor: local
    name: "跳过部署"
    steps:
      - name: log
        run: |
          echo "Deployment skipped due to quality gate failure"
          echo '```flowx-yaml'
          echo 'skipped: true'
          echo 'reason: "Quality gate failed"'
          echo '```'

  RejectProduction:
    executor: local
    name: "拒绝生产部署"
    steps:
      - name: reject
        run: |
          echo "Production deployment rejected!"
          echo "Please fix quality issues before deploying to production"
          echo '```flowx-yaml'
          echo 'rejected: true'
          echo 'reason: "Quality gate failed"'
          echo '```'

Docker 构建工作流

Version: "1.0"
Name: docker-build-example
Description: "Docker Executor 示例 - 展示如何使用 Docker 执行器运行完整的 CI 流水线"

Metadate:
  type: in-config
  description: "存储构建过程中的元数据"
  data:
    projectName: "{{ Param.appName }}"
    buildVersion: "{{ Param.version }}-{{ Param.buildId }}"
    buildTime: "{{ now }}"

Param:
  appName: "myapp"
  version: "1.0.0"
  buildId: "build-001"
  goVersion: "1.21"
  workDir: "/app"
  outputDir: "./output"
  testTimeout: "30s"
  coverageThreshold: 80

Executors:
  docker-alpine:
    type: docker
    description: "Docker 执行器 - Alpine 镜像"
    config:
      registry: "hub.rat.dev"
      network: bridge
      workdir: /app
      env:
        CGO_ENABLED: "0"
      tty: false

  docker-golang:
    type: docker
    description: "Docker 执行器 - Golang 镜像"
    config:
      registry: "proxy.vvvv.ee"
      network: bridge
      workdir: /app
      env:
        CGO_ENABLED: "0"
        GOOS: linux
        GOARCH: amd64
        GOPROXY: https://goproxy.cn,direct
      tty: false

Nodes:
  Checkout:
    name: "代码检出"
    executor: docker-alpine
    extract:
      type: codec-block
    steps:
      - name: init
        run: |
          echo "初始化工作目录..."
          mkdir -p /app/src
          echo '```flowx-yaml'
          echo 'status: "initialized"'
          echo 'workDir: "/app/src"'
          echo '```'
      - name: clone
        run: |
          echo "正在克隆代码..."
          echo "项目: {{ Param.appName }}"
          echo "版本: {{ Param.version }}"
          cd /app/src
          echo "代码克隆完成"
          echo '```flowx-yaml'
          echo 'commit: "abc123"'
          echo 'branch: "main"'
          echo 'files: 42'
          echo '```'

  Build:
    name: "编译构建"
    executor: docker-golang
    extract:
      type: codec-block
    steps:
      - name: version
        run: |
          echo "Go 版本:"
          go version
          echo "GOPROXY: $GOPROXY"
      - name: build
        run: |
          echo "开始编译 {{ Param.appName }}..."
          cd /app/src
          echo "下载依赖..."
          echo "编译二进制文件..."
          echo "构建完成"
          mkdir -p /output
          echo '```flowx-yaml'
          echo 'binary: "{{ Param.appName }}"'
          echo 'version: "{{ Param.version }}"'
          echo 'buildId: "{{ Param.buildId }}"'
          echo 'size: "15MB"'
          echo 'output: "/output/{{ Param.appName }}"'
          echo '```'
      - name: verify
        run: |
          echo "验证构建产物..."
          ls -la /output/ 2>/dev/null || echo "输出目录已准备"

  Test:
    name: "运行测试"
    executor: docker-golang
    extract:
      type: codec-block
    steps:
      - name: unit-test
        run: |
          echo "运行单元测试..."
          cd /app/src
          echo "测试包: ./..."
          echo "超时: {{ Param.testTimeout }}"
          echo "=== 测试结果 ==="
          echo "PASS: TestMain"
          echo "PASS: TestHandler"
          echo "PASS: TestService"

运行方式

方法一：使用 Go 库

package main

import (
    "context"
    "fmt"
    "os"

    "github.com/LerkoX/flowx"
)

func main() {
    ctx := context.Background()

    // 加载配置文件
    configData, err := os.ReadFile("file_processing.yaml")
    if err != nil {
        fmt.Printf("读取配置文件失败: %v\n", err)
        os.Exit(1)
    }

    // 创建运行时
    runtime := flowx.NewRuntime(ctx)

    // 运行流水线
    pipelineID := "my-pipeline"
    pipeline, err := runtime.RunSync(ctx, pipelineID, string(configData), nil)
    if err != nil {
        fmt.Printf("流水线执行失败: %v\n", err)
        os.Exit(1)
    }

    fmt.Printf("流水线 %s 执行完成！状态: %s\n", pipeline.Id(), pipeline.Status())
}
