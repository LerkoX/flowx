执行器系统

FlowX 支持三种执行后端：Local（本地 Shell）、Docker（容器）、Kubernetes（Pod）。三种执行器通过统一的 Executor 接口工作，可在配置中无缝切换。

概述

执行器系统的核心接口：

type Executor interface {
    Prepare(ctx context.Context) error
    Destruction(ctx context.Context) error
    Transfer(ctx context.Context, resultChan chan<- any, commandChan <-chan any, inputChan <-chan []byte)
}

生命周期：

Prepare → Transfer（可多次执行命令）→ Destruction

Provider 使用注册的执行器配置，通过 Adapter/Bridge 模式创建执行器实例。支持的类型字符串：

类型说明
local本地 Shell 执行
dockerDocker 容器执行
kubernetes / k8sKubernetes Pod 执行

Local 执行器

在本地 Shell 环境中执行命令。

配置项

配置键类型说明
workdirstring工作目录，必须存在
envmap[string]string环境变量
shellstringShell 类型（bash/sh/zsh）
timeoutstring/int单命令超时（如 "60" 或 "2m"）
ptybool是否使用 PTY（交互式程序）
ptyWidthintPTY 宽度
ptyHeightintPTY 高度

Shell 自动检测

  • Unix：优先 bash，回退 sh
  • Windows：优先 pwsh/powershell，回退 cmd

行为特点

  • Prepare：验证工作目录存在、配置的 Shell 可用
  • Transfer：通过 os/exec 执行命令，实时流式输出 stdout 和 stderr
  • 交互式输入：支持通过 inputChan 向进程 stdin 发送数据
  • 取消：先发送 os.Interrupt，不响应则 Process.Kill()
  • 超时：支持单命令级别超时
Executors:
  local:
    type: local
    config:
      shell: bash
      workdir: /tmp/build
      env:
        KEY: value
      timeout: 60
      pty: false

Docker 执行器

在 Docker 容器中执行命令。

配置项

配置键类型说明
registrystring默认镜像仓库前缀
networkstring容器网络模式
workdirstring容器内工作目录
volumes[]string挂载卷列表，格式 "host:container"
envmap[string]string环境变量
ttybool启用 TTY
ttyWidthintTTY 宽度
ttyHeightintTTY 高度

行为特点

  • Prepare：创建容器（初始命令 sleep 3600），镜像不存在时自动拉取
  • Transfer：通过 Docker exec API 在容器内执行命令，实时流式输出
  • Shell 检测：Alpine/Busybox 镜像使用 /bin/sh，其他使用 /bin/bash
  • 隔离性：每个执行器对应一个独立的容器实例
  • 容器复用：同一个执行器可执行多个命令（容器持续运行）
Executors:
  docker:
    type: docker
    config:
      registry: myregistry.com
      network: host
      workdir: /app
      volumes:
        - /var/run/docker.sock:/var/run/docker.sock
        - ${PWD}:/workspace
      env:
        GO_VERSION: "1.21"
      tty: true

Kubernetes 执行器

在 Kubernetes Pod 中执行命令。

配置项

配置键类型说明
namespacestringK8s 命名空间
workdirstring工作目录
envmap[string]string环境变量
serviceAccountstringServiceAccount 名称
configMaps[]mapConfigMap 挂载
secrets[]mapSecret 挂载
volumes[]mapPVC 挂载
emptyDirs[]mapEmptyDir 挂载
podReadyTimeoutintPod 就绪超时秒数（默认 60）
resourcesmap资源限制（cpu/memory）

资源配置示例

config:
  resources:
    cpu: "1000m"
    memory: "2Gi"

卷挂载示例

config:
  configMaps:
    - name: my-config
      mountPath: /etc/config
  secrets:
    - name: my-secret
      mountPath: /etc/secrets
  volumes:
    - name: data-volume
      mountPath: /data
  emptyDirs:
    - name: temp-data
      mountPath: /tmp/data

行为特点

  • Prepare：创建 Pod（初始命令 sleep 3600），等待 Pod 进入 Running 状态（默认超时 60 秒）
  • Transfer：通过 Kubernetes exec API（SPDY 协议）在 Pod 内执行命令，实时流式输出
  • Destruction：使用独立的 background context（30 秒超时）确保清理，优雅终止期为 10 秒
  • 取消：通过 stdin pipe 发送 Ctrl+C（\x03）终止远程进程
Executors:
  k8s:
    type: kubernetes
    config:
      namespace: default
      serviceAccount: pipeline-sa
      resources:
        cpu: "1000m"
        memory: "2Gi"
      podReadyTimeout: 60
      configMaps:
        - name: my-config
          mountPath: /etc/config

Provider 工厂

Provider 使用注册的执行器配置，通过 Adapter/Bridge 模式创建执行器实例。

provider := provider.NewProvider()

// 注册执行器
provider.RegisterExecutor("local", executor.ExecutorConfig{
    Type:   "local",
    Config: map[string]any{"shell": "bash"},
})
provider.RegisterExecutor("docker", executor.ExecutorConfig{
    Type:   "docker",
    Config: map[string]any{"registry": "myregistry.com"},
})

// 创建并准备执行器
exec, err := provider.GetExecutor(ctx, "docker")

创建流程：

  1. RegisterExecutor(name, config)
  2. GetExecutor(ctx, name)
  3. 根据 type 选择 Adapter 和 Bridge
  4. Adapter.Config() 应用配置
  5. Bridge.Conn() 创建 Executor
  6. Executor.Prepare() 初始化环境
  7. 返回准备好的 Executor

执行器生命周期

每个执行器在流水线中的生命周期如下：

    Prepare --> Transfer[Executor.Transfer
    执行命令]
    Transfer --> Output[实时流式输出]
    Transfer --> More{更多命令?}
    More -->|是| Transfer
    More -->|否| Destruction[Executor.Destruction
    清理环境]
    Destruction --> End([Pipeline 完成])

    Destruction --> Local
    Destruction --> Docker

1. Pipeline 启动
   └── 为每个节点创建/复用执行器
       └── Executor.Prepare() 初始化环境

2. 节点执行
   └── Executor.Transfer() 执行命令
       └── 实时流式输出到日志

3. Pipeline 完成或取消
   └── Executor.Destruction() 清理环境
       └── Local: 关闭 Shell 进程
       └── Docker: 停止并删除容器
       └── K8s: 删除 Pod
