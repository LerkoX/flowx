配置参考

Version

配置文件格式版本，用于引擎兼容性判断。

属性说明
类型string
必填是
示例"1.0"

Name

流水线名称，用于标识、日志和监控。

属性说明
类型string
必填是
示例my-pipeline

Metadate（元数据配置）

定义元数据的存储后端和初始数据。元数据用于在节点间传递数据。

字段说明

字段类型说明
typestring存储类型：in-config、redis、http
descriptionstring可选，描述元数据用途
datamap初始元数据键值对，支持模板渲染

FieldItem 格式

Metadate.data 中的每个字段支持两种格式：

1. 简单格式（推荐）：

Metadate:
  type: in-config
  data:
    K8sNamespace: "{{ Param.namespace }}"  # Kubernetes 命名空间
    FullImage: "{{ Param.registry }}/myapp:{{ Param.env }}"  # 完整镜像地址

2. 完整格式：

Metadate:
  type: in-config
  data:
    K8sNamespace:
      value: "{{ Param.namespace }}"
      description: "Kubernetes 命名空间"
      srcNode: ""  # 空表示来自配置，节点产生时会自动填充
提示：更多详情参见 元数据存储 文档。

Param（参数定义）

全局变量池，支持模板渲染和自引用。所有参数可在 Nodes.steps[].run、Edge 表达式和 Metadate.data 中引用。

特性

  • 基本引用：通过 {{ Param.xxx }} 引用其他参数
  • 自引用：一个 Param 可以引用另一个 Param 的值，最多迭代 10 次
  • 嵌套结构：支持 map 和 list 嵌套
  • 未定义变量：引用未定义变量时，模板表达式保持原样不变

示例

Param:
  env: "production"  # 部署环境: dev, staging, 或 production
  appName: "myapp"   # 应用名称
  # 自引用
  namespace: "{{ Param.appName }}-{{ Param.env }}"         # 渲染为: myapp-production
  registry: "myregistry.com"
  # 多层引用
  imageName: "{{ Param.registry }}/{{ Param.appName }}"    # 渲染为: myregistry.com/myapp
  fullImage: "{{ Param.imageName }}:latest"                # 渲染为: myregistry.com/myapp:latest
  # 嵌套结构
  config:
    replicas: 3
    envVars:
      - name: "ENVIRONMENT"
        value: "{{ Param.env }}"

Executors（执行器定义）

全局执行器注册表，供 Nodes 引用。支持 local、docker、kubernetes（或 k8s）三种类型。

通用字段

字段类型说明
typestring执行器类型：local / docker / kubernetes
descriptionstring可选，执行器用途说明
configobject执行器配置，被 Nodes 继承

各类型执行器的详细配置参见 执行器系统 文档。

Logging（日志配置）

配置日志推送服务，将执行日志发送到外部系统。

字段类型说明
endpointstring日志接收服务 HTTP 接口地址
headersmap请求头（认证、租户标识等）
timeoutduration单次推送超时时间（如 5s）
retryint推送失败重试次数
 
Logging:
  endpoint: http://log-center/api/v1/logs
  headers:
    Authorization: Bearer xxxxxxxxx
  timeout: 5s
  retry: 3

Graph（流程定义）

使用 Mermaid stateDiagram-v2 语法定义节点执行顺序和依赖关系。

基本语法

Graph: |
  stateDiagram-v2
    [*] --> Build
    Build --> Test
    Test --> Deploy
    Deploy --> [*]

条件边

边的标签中可以嵌入 pongo2 表达式作为条件：

Graph: |
  stateDiagram-v2
    [*] --> Check
    Check --> Deploy : {{ Param.env == "production" }}
    Check --> Skip   : {{ Param.env != "production" }}
提示：更多条件边语法参见 条件边与循环 文档。

并行执行

多个节点从同一节点出发即可实现并行：

Graph: |
  stateDiagram-v2
    [*] --> Task1
    [*] --> Task2
    [*] --> Task3
    Task1 --> Merge
    Task2 --> Merge
    Task3 --> Merge
    Merge --> [*]

MaxLoopIterations（循环迭代上限）

循环图最大迭代次数，超过则返回错误。默认值 100。

MaxLoopIterations: 5

Graph: |
  stateDiagram-v2
    [*] --> A
    A --> B
    B --> C
    C --> A: {{ iteration < 3 }}
    C --> D
    D --> [*]

Status（运行时状态）

节点运行时状态，用于快照恢复。键为节点名，值为状态枚举。

状态值含义
Pending等待执行
Running执行中
SUCCESS执行成功（恢复时会跳过）
FAILED执行失败（恢复时会跳过）
CANCELLED已取消
PAUSED已暂停
STOPPED已停止
ABORTED已终止

Nodes（节点配置）

定义每个节点的执行器、步骤、输出提取等。

节点字段

字段类型必填说明
executorstring是引用 Executors 中定义的执行器名称
imagestring否容器镜像（Docker/K8s 执行器使用）
steps[]Step是执行步骤列表
extractobject否输出提取配置
runtimeobject否节点运行时状态（用于恢复）

Step 字段

字段类型必填说明
idstring否步骤唯一标识（自动生成）
namestring是步骤名称
descriptionstring否步骤描述
runstring是执行的 shell 命令（支持模板渲染）

输出提取配置

字段类型默认值说明
typestringcodec-block提取类型：codec-block 或 regex
patternsmap-正则表达式（type=regex 时使用）
maxOutputSizeint1048576 (1MB)输出大小限制（字节）
 
Nodes:
  Build:
    executor: local
    steps:
      - name: build
        run: echo "Building..."
    extract:
      type: codec-block
      maxOutputSize: 1048576

  Test:
    executor: local
    extract:
      type: regex
      patterns:
        coverage: "coverage: (\\d+\\.\\d+)%"
        tests: "(\\d+) tests? passed"
    steps:
      - name: test
        run: go test -cover
